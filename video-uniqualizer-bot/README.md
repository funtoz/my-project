# Video Uniqualizer Bot

Telegram бот для уникализации вертикальных видео (TikTok, YouTube Shorts, Reels)

## 🎯 Возможности

- ✅ Многослойная уникализация видео
- ✅ Незаметные изменения (шум, цветокоррекция, метаданные)
- ✅ Высокое качество выходного видео
- ✅ Поддержка видео до 3 минут
- ✅ Только вертикальные видео

## 🛠 Технологии

- Python 3.9+
- aiogram 3.15 (Telegram Bot API)
- FFmpeg (обработка видео)
- python-dotenv (конфигурация)

## 📦 Установка

### 1. Установи Python
Скачай и установи Python 3.9+ с [python.org](https://www.python.org/downloads/)

**Важно:** При установке поставь галочку "Add Python to PATH"

### 2. Установи FFmpeg

**Windows:**
1. Скачай FFmpeg: https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
2. Распакуй в `C:\ffmpeg`
3. Добавь в PATH: `C:\ffmpeg\bin`
   - Пуск → "Переменные среды" → PATH → Добавить

**Проверка установки:**
```powershell
ffmpeg -version
```

### 3. Установи зависимости

```powershell
cd E:\Work\video-uniqualizer-bot
pip install -r requirements.txt
```

### 4. Создай Telegram бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Придумай имя и username для бота
4. Скопируй токен (например: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 5. Настрой конфигурацию

Скопируй `.env.example` в `.env`:
```powershell
Copy-Item .env.example .env
```

Открой `.env` и вставь свой токен:
```
TELEGRAM_BOT_TOKEN=твой_токен_здесь
```

## 🚀 Запуск

```powershell
cd E:\Work\video-uniqualizer-bot
python main.py
```

Если всё настроено правильно, увидишь:
```
INFO - Бот успешно запущен и готов к работе!
```

2. Отправь `/start`
3. Отправь вертикальное видео

## 🎨 Методы уникализации

**Слой 1 - Метаданные:**
- Полная перезапись всех метаданных
- Уникальный UUID

**Слой 2 - Видео:**
- Шум 1-2% на кадры
- Микро-crop 2-4px + resize
- Изменение скорости ±2-4%
- HSV цветокоррекция ±2%
- Микроизменение FPS

**Слой 3 - Аудио:**
- Изменение питча ±0.3-0.7%
- Задержка 20-100мс

**Слой 4 - Кодирование:**
- Новые параметры H.264
- Случайные вариации битрейта

## ⚙️ Настройки

Измени параметры в `.env`:

```env
# Ограничения
MAX_VIDEO_DURATION=180        # Максимальная длительность (сек)
MAX_FILE_SIZE_MB=500          # Максимальный размер файла (МБ)

# FFmpeg
FFMPEG_THREADS=4              # Количество потоков (больше = быстрее)
VIDEO_QUALITY=23              # CRF качество (18-28, меньше = лучше)
```

## 🐛 Решение проблем

**"TELEGRAM_BOT_TOKEN не установлен"**
- Проверь, что файл `.env` создан и содержит токен

**"ffmpeg not found"**
- FFmpeg не установлен или не добавлен в PATH
- Перезапусти PowerShell после установки

**"Ошибка при обработке видео"**
- Проверь формат видео (должен быть MP4/MOV)
- Проверь, что видео вертикальное
- Проверь логи в `bot.log`

**Бот не отвечает**
- Проверь, запущен ли `main.py`
- Проверь токен бота
- Проверь интернет-соединение
