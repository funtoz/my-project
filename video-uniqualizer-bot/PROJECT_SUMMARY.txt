## 🎨 Методы уникализации:

✅ Метаданные - полная перезапись + UUID
✅ Шум 1-2% - незаметный для глаза
✅ Микро-crop 2-4px + resize
✅ Скорость ±2-4% - случайное изменение
✅ Цветокоррекция HSV ±2%
✅ Изменение FPS
✅ Аудио питч ±0.3-0.7%
✅ Задержка аудио 20-100мс
✅ Вариация битрейта
✅ Пресет H.264 slow (качество)

## 🚀 Следующие шаги:

1. Установи Python 3.9+ (https://www.python.org/downloads/)
2. Установи FFmpeg (https://www.gyan.dev/ffmpeg/builds/)
3. Открой PowerShell и выполни:

   cd E:\Work\video-uniqualizer-bot
   pip install -r requirements.txt

4. Создай бота через @BotFather в Telegram
5. Скопируй .env.example в .env и вставь токен
6. Запусти: python main.py
